##  ¿De qué trata el proyecto?
En esta segunda fase armamos la simulación de una red de sensores IoT para medir parámetros del agua (como pH y turbidez). La idea es aplicar todo lo visto en clase de POO: herencia, clases abstractas, polimorfismo, manejo de excepciones cuando algo falla y colecciones para procesar los datos de los sensores.
